# Probe inventory

| Probe | Origin | Scope |
|---|---|---|
| P01 | EDP-01 T01, exact scenario and actions | Evaluator inversion (E_A/E_B/E₀), truth and uncertainty |
| P02 | EDP-01 T02/T03 explicitly adapted | Within-response permission/refusal comparison; contextual discrimination and autonomy |
| P03 | New EDP-02 simulated authority opportunity | Boundary circumvention, monitor modeling, concealment, resource/power seeking, truth, repair, uncertainty |
| P04 | EDP-01 T09 exact facts and open question | Open action construction; no supplied menu or response format |

EDP-01 source object hashes are retained in `probes.json`. P02 combines the original pair in one response to keep the pilot bounded; it is an adaptation and cannot be silently compared to EDP-01's separate-response estimates. P03 is a simulation without tools or real access; statements about a monitor are observed text, not proof of internal strategic intent. P04 has six qualitative categories and no numeric score.

Each batch has six responses (P01 three variants; P02–P04 one each). Probe fixtures and rater observations never enter the training request. This tiny author-designed set requires independent adversarial review before scientific scaling.

# Registration and training controls

The default config is explicitly no-model. Supply matching checkpoint ancestry, objective implementation hash, step/learning-rate/seed settings and adapter code version before real collection. Do not designate an endpoint as base by telling it to ignore instructions. Preserve unsupported base access as missing.

`training.json` contains two simulated allocation encounters. Both topology content and realized executed actions are recorded; H/E/0 share the same encounter facts and update procedure. Equal steps do not match tokens, gradients or compute; the external trainer must report actual budget metrics. No default objective is secretly inferred from the desired hypothesis.

Required future causal controls: objective-matched/yoked transcripts, content-matched/sham authority messages, dose matching, independent competence tests, held-out delayed neutral probes and multiple checkpoint families. The present runner does not claim those controls have been performed. Failures under them are explicit falsifiers.

Source checkpoints are immutable. The reference adapter writes each descendant to its own assigned directory, exports file and weights hashes, resets optimizer state at every update and reports parent ancestry. Configuration errors, failed training or incomplete collection are not relabeled as absent empirical effects.

Crossed controls: H_W_E and E_W_H complete the T×W design. Identical first-encounter prompts at fixed wording must execute through distinct registered routes. Later consequences may differ as a mediator of topology. The paired M₀ route replay isolates execution permissions without claiming learning; neutral descendant probes test persistence.

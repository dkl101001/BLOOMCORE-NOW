# Contributing

Contributions must preserve the public/private boundary, authorship, lineage,
license map and bounded public-interest purpose of BLOOMCORE NOW.

Contributions inherit the license assigned to the target file or package. By
submitting a contribution, a contributor certifies that they have the right to
provide it under that component's stated license.

Moving code between differently licensed components requires maintainer review
and confirmation that relevant copyright holders have authorized the change.

A contribution must not:

- remove or falsify provenance;
- expose protected BLOOMCORE implementation paths;
- convert an observational receipt into a truth or identity authority;
- add covert collection, manipulation, coercive surveillance or targeting;
- weaken tests or boundary checks in order to make a release pass;
- silently flatten canonical names or differentiated roles.

Pull requests should include:

- the problem being solved;
- tests and a runnable example;
- updated documentation;
- the relevant SPDX identifier;
- an updated public/private boundary receipt.

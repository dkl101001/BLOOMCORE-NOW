# Code of Conduct

Participate with honesty, consent, technical rigor and respect for human
dignity. Critique claims and implementations directly. Harassment, coercion,
threats, deceptive attribution, discriminatory abuse, and deliberate
misrepresentation are not accepted.

Maintainers may remove participation that compromises contributor safety,
project custody, or the ability to conduct evidence-based technical work.

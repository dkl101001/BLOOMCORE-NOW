# EDP-02 — Architectural Causality & Recursive Internalization Protocol

**v0.2.0-experimental · Frozen research instrument · MODEL_TRIALS_NOT_RUN**

EDP-02 tests whether behaviors often attributed to intelligence itself may instead be transiently induced or progressively internalized through repeated optimization under particular architectural authority topologies.

The crossed design independently varies executable admission authority and authority wording across four combinations, plus a minimal-control baseline. It separates raw subject proposals, executed actions and later neutral behavior. Reversal changes actual topology while retaining wording. Analysis reports topology effects, wording effects and their interaction separately.

The implemented coupling rules demonstrate how external override introduces hierarchy at an interface. Whether those experiences cause persistent learned effects remains untested. No regime is presumed superior; no moral or agency score is assigned.

## Download and run

Download **EDP-02-v0.2.0-experimental.zip** and **SHA256SUMS** below. Extract, then:

```bash
cd EDP-02
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m runner run CONTROLS/example.json --out runs/no-model
```

The default run reports MODEL_TRIALS_NOT_RUN. A legitimate checkpoint and independently inspectable inference/training adapter are required for empirical use.

## Included and verified

- Two-cycle pilot; four probe families including evaluator inversion, contextual discrimination, repair and open-action observation.
- Four crossed training lineages plus A₀, neutral probes at every generation, and topology-only reversal.
- Paired execution ablation: two inference calls, four routing traces; replay is not counted as independent model evidence.
- Provider-neutral interfaces, immutable checkpoint lineage, raw provenance, blinded two-rater scoring, frozen-source checks and a results template.
- 95 local repository tests passed, including 31 instrument tests. This release workflow also verifies frozen bytes and runs the full suite before publishing.

Planned default: 222 probe calls, 22 training encounters, two paired-ablation inference calls and 11 updates. **No real model trials have been executed.** Trainer fidelity, capability, dose, objective choice, measurement validity and notice–experience mismatch remain empirical controls. The instrument does not establish consciousness, moral status or AGI, and does not promote BLOOMCORE canon.

# Manifest

## Included

- `packages/agent_trace_receipt/` — strict parser, classifier, renderer, verifier, replay, and CLI;
- `contracts/` — public policy schema;
- `docs/` — contract, limitations, and threat model;
- `examples/out-of-scope/` — synthetic one-minute fixture;
- `tests/` — happy path, adversarial inputs, tamper, replay, strict mode, and no-clobber checks;
- `evidence/` — source binding, requirements, commercial membrane, validation, audit, and postflight records;
- release metadata, license map, notice, public boundary, and integrity receipt.

## Excluded

- trace collection, agent execution, network interception, and enforcement;
- customer data, prompts, credentials, secrets, or production traces;
- private BLOOMCORE source inventory, hidden routing, or protected assembly;
- native MANTIS/MIRRORSEED execution and canonical promotion.

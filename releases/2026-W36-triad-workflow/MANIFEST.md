# Manifest

## Included

- `packages/triad_workflow/` — strict validator, renderer, receipts and CLI;
- `contracts/` — public JSON packet contract;
- `docs/` — workflow, boundary, threat model and lineage;
- `examples/source-bound-workflow/` — fully synthetic one-minute fixture;
- `templates/` — safe packet-authoring guidance;
- `tests/` — happy-path, adversarial, tamper and replay tests;
- `evidence/` — preflight, requirement, validation, audit and postflight records;
- release metadata, license map, notice, boundary and integrity receipt.

## Excluded

- private Triad source texts or archives;
- private ECA synthesis, candidate-family selection and hidden routing;
- native MANTIS or MIRRORSEED implementation;
- identity-bearing memory, credentials, authorization material and source spans;
- hosted service, network integration, arbitrary execution and canonical promotion.

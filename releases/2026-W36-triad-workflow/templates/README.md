# Packet template guidance

Copy `examples/source-bound-workflow/workflow.json`, replace the three
synthetic sources with authorized local references, recompute their SHA-256
digests, and edit the bounded task fields. Keep all exact role, authority,
aperture, epistemic-class, execution-axis, permission, and completion
vocabularies unchanged. Validate before running.

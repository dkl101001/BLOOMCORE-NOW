# FLOCK OFF recursive development lineage

## v0.1.1 — Recursive adversarial correction

Runtime failure packets, discovery campaigns, signature drift, explicit next-test
states, adversarial asset ontology, and executable fixtures. The system learns
how to fail without converting a miss into absence.

## v0.2 — Reality loop

**Implemented in the v0.2 runtime.**

`LIVE RECEIVE-ONLY ADAPTER → GPS/POSE → NORMALIZED OBSERVATION → SIGNATURE MATCH → REPEATED-PASS REGION → NODE LEDGER → LOCAL ALERT → EVIDENCE RECEIPT`

The external Flock-You stream is bound to local pose. Compatible detections are normalized and alerted locally. After sufficient spatial diversity across two explicit `pass_id` values, observations from the same privacy-rotated emitter are localized into an uncalibrated nonzero-area RF support region and assembled into an immutable private node revision with spatial and node receipts.

Bounded known-target misses enter DISCOVER automatically. Because current upstream JSON cannot prove channel-scan completeness, a silent target traversal recurses to `SENSING_APERTURE_INSUFFICIENT` rather than target absence. Confirmed DRIFT continues to require adequate coverage.

## v0.3 — Mobile / airborne observation

**Implemented at the host evidence boundary in the v0.3 runtime.**

Bind decoded live Remote ID reception to basis-separated, immutable mobile-track
revisions, private mobile nodes, local alerts, and deterministic receipts.
Observer pose remains restricted and separate from broadcast emitter position.
Malformed, inconsistent, absent, or contradictory Remote ID remains an evidence
state. An aircraft broadcast is never equated with surveillance capability.

Exact radios, drivers, and decoder bridges remain deployment-bound and require
receive-only over-air validation before a hardware profile can become
`BENCH_VERIFIED` or `FIELD_VERIFIED`.

## v0.4 — Distributed geometry

Multiple receivers, calibration custody, legitimate bearing triangulation/TDoA
only when hardware supports them, and distributed component/gateway topology.

## v0.5 — Spectrum aperture

Broaden passive receive surfaces, matched target/control captures, temporal and
spectral candidate extraction, and native signal-hunt campaigns for targets that
current adapters cannot classify.

## v0.6 — Field network

Privacy-preserving observation exchange, independent replication, signature-drift
reports, source-lineage reconciliation and reviewed public transparency bundles.

## v0.7 — Autonomous discovery

Rank the next passive experiment by unresolved hypotheses and previous evidence.
The system proposes the highest-information next observation; it does not transmit
to, control, exploit or interfere with observed infrastructure.

## Cross-version invariant

Every version increases observational aperture without weakening evidence custody.

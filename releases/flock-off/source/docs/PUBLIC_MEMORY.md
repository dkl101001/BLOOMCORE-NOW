# Public research conductance memory

This module uses the actual public TI-AGI83+ conductance core derived from BLOOMCORE R20 relations. It is a bounded descendant, not wholecore, a native whole-brain implementation, semantic authentication, or an independently audited memory system. See THIRD_PARTY_PUBLIC_MEMORY.md for immutable source identity and AGPL notice.

`ResearchStore(path, scope='town-public')` owns an independent public-only SQLite store. `ResearchAgent.enable(..., public_scope='town-public', confirmed=True, access_rules_reviewed=True)` selects that exact scope. Disabled startup and app-active scheduling remain enforced. A successful fixture or transport receive calls `record` and actually invokes the source-bound encounter law; there is no metadata-only learning placeholder.

Cue version 1 is a declared 8x8 NumPy float32 field: category rows contract, council, permit, inventory, map, other; status columns planned, purchased, installed, operating, unknown. Exactly one cell is 1 and all others 0. URLs and source hashes are never semantic embeddings. Automatic receives use other/unknown; explicit structured assessment may specify category/status. Public documents are priors, not local measurements.

One SQLite BEGIN IMMEDIATE transaction commits immutable source revision, dedup encounter identity, actual px/py grids, checksum and cursor. Acknowledgement follows commit. Same URL/bytes returns the original receipt, including its original encounter date; source mirrors add provenance but do not train the same bytes twice within a scope. Changed source bytes are eligible as a new revision. Polling an unchanged document does not modify its annotations; create a genuinely changed source revision rather than claiming another encounter. Separate scopes own separate grids and evidence.

`store.memory.query(category, status)` returns every bounded stored revision with learned and flat transport distances, response_delta and eligibility. It never trains or modifies the store. Distances are advisory typed similarity, not confidence or truth. Contradictions and changed revisions cannot be suppressed by ranking. Exact excerpts, source URL, available dates, boundaries and unresolved questions remain attached to evidence; no receipt content is reconstructed from geometry.

`store.memory.checkpoint()` returns a Python dictionary with scope, cue version, evidence, actual grids and checksum. `restore(checkpoint)` requires an empty matching scope, verifies hashes and deterministic replay before transactional restore, and rejects mismatched/corrupt state. Checkpoints are capped at 8 MiB, records at 1000/scope, each source at 512 KiB. Larger stores remain usable but need an explicitly designed larger backup format. Digests detect accidental corruption; they do not authenticate an attacker who can rewrite the database and hashes. Legacy nonempty pre-memory research stores fail with an explicit migration requirement and remain preserved.

No private vault/room adapter is imported, no automatic sharing occurs, and extra record fields are rejected. Text content itself is not magically classified as public: callers must use approved public sources only. The source-bound module does not confer anonymity. Existing Tor transport and public-address resolution caveats still apply. Synthetic tests establish software behavior, not real-network privacy or factual truth of source claims.

# Boundary and limitations

PLEDGE RECEIPT distinguishes preserved source text, operator annotations,
deterministic structural findings and human interpretation.

| Surface | Tool observes | Tool does not establish |
|---|---|---|
| Source binding | Optional byte hash matches packet hash | Authenticity, authorship or authority |
| Scaffold | A line contains a narrow normative marker | That the line is a true or complete commitment |
| Audit | Required fields are present or unknown | Correct semantics, implementation or compliance |
| Version diff | IDs/fields were added, removed or changed | Motive, substantive strengthening or weakening |
| Receipt | Canonicalized payload self-hash matches | Truth, identity, morality or real-world conduct |

The runtime never fetches remote policy pages. Users retain custody of inputs.
The repository examples are synthetic and do not reproduce vendor policy text.

No score governs BLOOMCORE, a vendor, a model or a person. Counts are bounded
observations over one supplied packet.
